# CubeTerre

Un petit jeu de blocs en 3D inspiré de Minecraft, dans un seul fichier HTML (Three.js).

## Jouer

Ouvre `index.html` dans un navigateur (une connexion Internet est nécessaire pour charger Three.js).
Avec GitHub Pages activé sur ce dépôt, le jeu est jouable directement en ligne.

## Fonctionnalités

- Monde de 160×160 blocs généré aléatoirement à chaque partie : collines, montagnes, eau, plages, arbres
- Textures pixel art générées par le code, occlusion ambiante dans les coins
- Soleil carré et nuages en blocs qui défilent
- Déplacement à la première personne avec gravité, saut, collisions et nage
- 9 blocs à casser et poser : herbe, pierre, pavé, planches, bûche, feuilles, briques, verre, sable

## Commandes

| Touche | Action |
|---|---|
| ZQSD / WASD | se déplacer |
| Espace | sauter, nager vers le haut |
| Maj | courir (descendre en vol) |
| Souris | regarder |
| Clic gauche / droit | casser / poser un bloc |
| 1-9 / molette | choisir le bloc |
| F | activer ou couper le vol |
| Flèches | tourner la vue au clavier |
| Échap | pause |
